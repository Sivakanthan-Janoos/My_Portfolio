## About

This repository contains a static personal portfolio website built primarily with HTML and CSS and a small amount of JavaScript. It's intended to showcase projects, experience, and contact details in a simple, accessible layout.

## Features

- Responsive layout for desktop and mobile
- Project showcase section with links and descriptions
- Contact section with a contact form or mailto link
- Simple animations and styling using CSS

## Tech stack

The project is a static site using:
- HTML (majority of the markup)
- CSS (styling and responsive design)
- JavaScript (small interactive enhancements)

## Getting started

1. Clone the repository:

   git clone https://github.com/Sivakanthan-Janoos/My_Portfolio.git

2. Open `index.html` in your browser, or serve the directory with a static server:

   - Using Python 3: `python -m http.server 8000`
   - Then open `http://localhost:8000` in your browser.

No build tools are required — edit the HTML/CSS/JS files directly and refresh to see changes.

## Deployment (GitHub Pages)

To deploy this site with GitHub Pages:

1. Go to the repository on GitHub.
2. Settings -> Pages (or in the repository Settings sidebar).
3. Under "Source", select the default branch (e.g., `main` or `master`) and the root folder `/`.
4. Save. Your site will be published at `https://<your-github-username>.github.io/My_Portfolio` once the build completes.
